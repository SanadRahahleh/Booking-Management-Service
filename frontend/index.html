Booking Management Dashboard

Welcome to the administrative portal for shared resource scheduling. This interface communicates directly with the ASP.NET Core 10 Web API backend, enforcing strict interval overlap detection, serializable database transactions, and idempotent soft cancellation.

Quick Actions

Engineered Backend Invariants

Half-Open Intervals [Start, End)

Bookings are validated such that back-to-back reservations (e.g. 10:00–11:00 and 11:00–12:00) never collide.

Concurrency & Deadlock Resilience

Serializable database transactions protect against double bookings, backed by a bounded retry algorithm for SQL contention.

Soft Cancellation & Auditability

Cancelled bookings remain in the database for auditing and release their time slots immediately for new bookings.
